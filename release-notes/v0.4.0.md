Code is now colored by its language wherever snoop shows it: in the Diff tab, a file's history, the timeline's detail pane and permission prompts. The colors come from snoop's own palette, and added and removed lines stay easy to tell apart.

- **Colored code:** Edits, writes and diffs are colored by the language the file's name suggests, such as Go, Python or TypeScript, and a file in a language snoop doesn't recognize stays plain.
- **Tinted diff lines:** In a terminal with true color, added and removed lines in the Diff tab sit on a green or red tint under the code's colors.
- **Colored before you look:** The newest edits and writes are colored in the background as a session opens and as calls arrive, so code shows up already colored, and a short wait shows a spinner rather than plain text.
