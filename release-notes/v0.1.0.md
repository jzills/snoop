The first release of snoop shows what your Claude Code agents are doing, live in a second terminal or long after, from the transcripts they already write.

- **Follow a session live:** Run `snoop --follow` beside `claude`, and every prompt, reply and tool call appears as it happens, each prompt with its tokens, cost and duration.
- **Where the time went:** Selecting a prompt shows a waterfall of its tool calls, where calls that ran in parallel overlap.
- **Subagents inline:** Press `x` on an Agent call to expand its subagent's work under it, live while it runs.
- **Every session at once:** The live board, opened with `snoop --live`, lists every running session with the ones waiting on you first.
- **Review and comment:** Comments you leave on a line in the Diff tab reach the agent on their own, once `snoop hooks install` has added the hooks.
- **Find any session:** Press `f` in the picker to find sessions by a file they changed, a command they ran or a prompt.
