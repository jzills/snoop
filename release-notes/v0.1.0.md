This is the first release of snoop, a terminal viewer for Claude Code session
transcripts. You can watch a session live or browse past ones, with context
and cost per prompt, a waterfall for each turn, a Files tab, subagents inline,
alerts while you watch, copy and Markdown export, and a summary across every
session. The live board shows every running session at once, most urgent
first, and find looks up sessions by a file, a command or a prompt. On the
Diff tab you can review what a session changed and comment on its lines, and
the comments reach the agent through Claude Code hooks.
