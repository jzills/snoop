You can now answer an agent's permission prompts without switching to its terminal, and review its whole branch before it opens a pull request.

- **Answer permission prompts:** A session waiting on one shows as `? asking` on the live board, where `A` allows the call once and `D` denies it with a reason Claude sees.
- **The whole branch:** The Diff tab's Branch scope shows everything a branch changed since its base, and pressing `b` switches back to the uncommitted changes.
- **Cost while it runs:** The redesigned Stats tab estimates a running session's cost from its tokens, marked `≈` until Claude Code records the real one.
- **Folders and sorting:** The Files tab can show a tree of folders with `T`, and `o` sorts the picker and the live board by any column.
- **More ways to install:** The `snoop-cli` package installs from npm and PyPI, as in `npm install -g snoop-cli`, and Windows has a PowerShell script.

**After upgrading:** If you installed the hooks in v0.1.0, run `snoop hooks install` again so the live board can answer permission prompts.
