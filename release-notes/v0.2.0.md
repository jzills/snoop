You can now answer permission prompts from snoop. On the live board or in a
session, press `A` to allow a waiting tool call once, or `D` to deny it with
a reason, and the board shows sessions waiting on a prompt as asking. The
Diff tab can review a whole branch against its base, not just uncommitted
changes, so you can review an agent's work locally before opening a pull
request. The Files tab can show a tree of folders, the picker and the live
board sort by any column, and the Stats tab is redesigned, with costs
estimated while a session is still running. It also installs from npm
(`npm install -g snoop-cli`), PyPI (`pipx install snoop-cli`) and, on
Windows, a PowerShell script.
