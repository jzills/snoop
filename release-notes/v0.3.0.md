A finished turn can now wait for your reply from snoop, and two new alerts catch a session that runs away.

- **Reply when it's your turn:** Press `R` on the live board or in a session's view, and the agent carries on as if you'd typed the message in its terminal.
- **About the selected call:** In the Timeline and Tools tabs, a reply quotes the selected call or message first, so "this failed, try X" needs no copying.
- **Always allow:** Pressing `Y` on a permission request allows it and stops Claude Code asking again, as its own "don't ask again" does.
- **Runaway sessions:** The `--cost-alert 5` flag raises an alert each time a session spends another $5, and `--long-turn 15m` raises one when a turn runs that long.
- **Trees and comments:** The Diff tab can show its files as a tree with `T`, and the Files tab takes comments on a session's changes.

**After upgrading:** If you installed the hooks before v0.3.0, run `snoop hooks install` again so finished turns can wait for a reply.
