You can now reply to an agent from snoop. When a session's turn ends, press `R` on the live board or in its view, type a message, and the agent carries on as if you'd typed it in its terminal; in the Timeline and Tools tabs, the reply quotes the selected call or message first. Typing in the session's own terminal still works as before and never waits for snoop. Press `Y` on a permission request to allow it and stop Claude Code asking again, as its own "don't ask again" does. Two new alerts catch runaway sessions: `--cost-alert 5` each time a session spends another $5, and `--long-turn 15m` when a turn runs that long. The Diff tab can show its files as a tree with `T`, `E` opens or closes folders from the cursor, and the Files tab takes comments on a session's changes. If you installed snoop's hooks before this release, run `snoop hooks install` again so finished turns can wait for a reply.
