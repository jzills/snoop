A terminal viewer for Claude Code sessions

Follow a session live from a second terminal, or open any past one to see what it cost, which files it changed and where the time went. snoop reads the transcripts Claude Code already writes. Nothing leaves your machine.

Get started Documentation
curl -fsSL https://jzills.github.io/snoop/install.sh | sh

macOS, Linux and Windows. Also brew install jzills/tap/snoop.

Follow a session live

Run snoop --follow beside claude. Every prompt, reply and tool call appears as it happens, with diffs, commands and results in full.

Following a session

See cost, context and time

Each prompt shows its tokens, estimated cost and duration. A waterfall shows where a turn’s time went, and the header shows how full the context is.

Cost and context

Watch every session at once

The live board lists every session at work across your projects and which ones are waiting on you. --notify tells you when one needs you.

The live board

Know which session needs you

Running several sessions at once? The live board shows each one’s state: waiting on a permission prompt, your turn, or still working. Desktop notifications name the session and what happened, so you can work elsewhere and come back when it matters.

Read about the live board

Install snoop

One binary, nothing to configure. Run snoop to pick a session.
