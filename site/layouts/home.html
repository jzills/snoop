Keep an eye on your agents

Monitor your AI agents in real time. Follow active sessions from a second terminal or inspect past sessions to understand costs, file changes, and time spent. It reads existing agent transcripts, with no modifications and no data leaving your machine.

It supports Claude Code sessions only.

Get started Documentation
curl -fsSL https://jzills.github.io/snoop/install.sh | sh

It runs on macOS, Linux and Windows, and you can also install it with brew install jzills/tap/snoop.

Who needs you now

When you run several sessions at once, the live board shows each one’s state: waiting on a permission prompt, your turn, or still working. Desktop notifications name the session and what happened, so you can work elsewhere and come back when it matters.

Read about the live board

Every file an agent touched

The Files tab lists every file the session and its subagents read, edited or wrote, with lines added and removed. Step through a file’s history one diff at a time, or jump to the call that made a change.

Read about files and diffs

Reviews in the loop

The Diff tab shows what the session changed in its working tree. Comment on a line, a range or a whole file, and press S to send them all. While the agent is working, it sees your comments after its current tool call, so you never type into its terminal. Running snoop hooks install once sets up the hooks that deliver them.

Read about review and comment

Install snoop

It’s a single binary with nothing to configure. Run snoop to pick a session.
